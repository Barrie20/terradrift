## Project Status

TerraDrift is an active research prototype. It is not yet a peer-reviewed
publication.

Current phase:
- Research design: in progress
- Pilot data collection: in progress
- Large-scale corpus: planned
- Manual validation: planned
- Peer-reviewed submission: not yet submitted
- External adoption: not yet established

All performance, scale, and security findings will be reported only after the
experiments are completed and independently reviewed.
